# Secure File Encryption Tool

A small Python project for learning the basic idea of file encryption and decryption.

## About the Project

I made this project to understand how file data can be transformed and restored using a simple encryption technique.

The program reads a file, creates an encrypted version, and then creates a decrypted version from the encrypted data.

## Features

- Reads file data
- Creates an encrypted copy
- Decrypts the encrypted copy
- Works with binary file data
- Simple command-line interface

## Technologies Used

- Python 3
- pathlib

## How to Run

Run the program with:

```bash
python file_encryptor.py
